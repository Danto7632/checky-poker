# Checky Poker

[English](README.md) | **日本語**

> **開発中です（未公開）。** checkypoker.pages.dev には現在、仮のページだけを置いています。

Checky Poker は、ブラウザで遊べる無料・非営利のテキサスホールデムです。友だちとピアツーピアで遊びます。ゲームサーバー、アカウント、会員登録はありません。

- **フレンドテーブル**: リンクかルームコードで友だちを招待します。カードはホストのブラウザが配ります。カードは Web Worker の中で封印され、各プレイヤーには自分から見えるテーブルの情報だけが届きます。
- **練習**: ルールで動くボットと対戦します。ページを一度読み込めば、練習はオフラインでも遊べます。
- **自分の API キー（任意）**: 自分の AI プロバイダーの API キーを使って、LLM ボットを席に座らせられます。キーはこのブラウザの中だけに保存され、選んだプロバイダーにだけ送られます。利用料金とプロバイダーの規約は利用者の責任です。
- **言語**: 英語、日本語。

## 現金は使いません

チップは金銭的価値のない遊び用のチップです。購入、売却、譲渡、換金はできません。賞品はありません。チップの補充は無料で、回数の制限もありません。Checky Poker を現金を賭けたゲームや、現金を賭けたゲームの記録に使ってはいけません。ギャンブルサービスへのリンクもありません。

## 開発

必要なもの: Node.js（[`.nvmrc`](.nvmrc) のバージョン）、npm。

```bash
npm ci                    # ワークスペースをインストール（packages/engine、packages/analysis、frontend）
npm run dev -w frontend   # Vite の開発サーバーを起動
npm test                  # すべてのテストを実行
npm run build             # frontend/dist に本番ビルド
```

`backend/` には、このリポジトリの過去にあったサーバー型の試作品 AIPOT のコードが休止状態で残っています。Checky Poker の一部ではなく、デプロイもしていません。
